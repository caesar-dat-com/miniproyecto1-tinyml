Conectar la placa

Cuatro caminos, un solo formato de línea.

📡

Bluetooth LE

Nano 33 BLE, o Uno con módulo HM-10. Sin cables: es el camino de la demo.

Servicio UART Nordic · notificaciones

Este navegador no trae Web Bluetooth. Usa Chrome o Edge de escritorio, o Chrome en Android.

📶

WiFi

Uno R4 WiFi o ESP32 sirviendo un WebSocket en la red local.

Página en HTTPS: el navegador bloquea ws:// sin cifrar. Sirve la app por HTTP local o pon el WebSocket detrás de TLS.

🔌

Serial USB

Cable directo. Cómodo para desarrollo y calibración.

115200 baudios · 8N1

Este navegador no trae Web Serial. Usa Chrome o Edge de escritorio.

Ojo: la guía exige que la placa no esté conectada al PC durante la entrega. Esta vía es solo para desarrollar.

🎲

Simulador

Gestos sintéticos con ruido. Sirve para jugar y probar sin hardware.
